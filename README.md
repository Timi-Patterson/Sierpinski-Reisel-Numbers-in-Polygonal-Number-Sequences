# Sierpiński Riesel Numbers in Polygonal Number Sequences
Coding work from research in finding Sierpiński, Riesel, and Sierpiński-Riesel Numbers in different Polygonal Number Sequences in the summer of 2025

This code was mainly used as a way to automate computations and gather information about the modulus of sequences quickly. While functions were created, much of the work required directly editing code, as it expanded in a way that was somewhat irregular and could not be easily made into universal functions.
